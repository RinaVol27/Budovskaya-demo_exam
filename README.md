# Требования к дизайну веб-приложения

## 1. Общие требования к дизайну
Дизайн веб-приложения должен обеспечивать:
* удобство использования;
* интуитивно понятный интерфейс;
* современный внешний вид;
* единый визуальный стиль;
* комфортную работу пользователя с системой.

Интерфейс должен быть разработан для использования на персональном компьютере с разрешением экрана 1920×1080 px (допускается адаптация под другие разрешения).
